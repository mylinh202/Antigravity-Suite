# Antigravity Voice Selector

Tiện ích mở rộng dành cho Antigravity IDE / VS Code hỗ trợ chọn, gán và tải trực tiếp mô hình giọng đọc AI tiếng Việt cho từng dự án ngay trên thanh trạng thái (Status Bar).

## Tính năng chính
- **Hiển thị trực quan**: Thể hiện giọng đọc hiện tại được gán cho dự án trên thanh trạng thái.
- **Menu chọn nhanh**: Bấm vào để chọn đổi giọng đọc từ danh sách các giọng có sẵn trong máy.
- **Tự động tải mô hình đám mây**: Tải trực tiếp các mô hình giọng đọc mới từ Hugging Face về máy kèm theo thanh tiến trình phần trăm thực tế (`0% -> 100%`).
- **Ghi nhớ theo Workspace**: Mỗi dự án ghi nhớ giọng đọc riêng biệt, không bị trùng lặp hay xung đột.

## Cài đặt thủ công
Sao chép thư mục này vào:
`~/.antigravity-ide/extensions/antigravity-voice-selector-1.0.0`
hoặc
`~/.vscode/extensions/antigravity-voice-selector`
và khởi động lại IDE.
