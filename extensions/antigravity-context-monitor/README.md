# Antigravity Context Monitor

Tiện ích mở rộng theo dõi mức độ tiêu thụ ngữ cảnh (Context Window) và cảnh báo tài nguyên thời gian thực cho Antigravity IDE / VS Code.

## Tính năng chính
- **Theo dõi ngữ cảnh thời gian thực**: Giám sát dung lượng token đã sử dụng trong phiên làm việc.
- **Cảnh báo ngưỡng quá tải**: Tự động đổi màu và cảnh báo trực quan khi dung lượng chạm ngưỡng 75% để nhắc nhở người dùng nén ngữ cảnh hoặc mở phiên mới, tránh tràn bộ nhớ mô hình.
- **Xem chi tiết phiên**: Nhấp vào thanh trạng thái để xem bảng phân bổ chi tiết và các tác vụ nhanh.

## Cài đặt thủ công
Sao chép thư mục này vào:
`~/.antigravity-ide/extensions/antigravity-context-monitor-1.0.0`
hoặc
`~/.vscode/extensions/antigravity-context-monitor`
và khởi động lại IDE.
